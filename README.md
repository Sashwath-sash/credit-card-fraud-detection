# credit-card-fraud-detection

Overview

This project builds an end-to-end fraud detection system on highly imbalanced financial transaction data.

Key Features
Handles extreme class imbalance (~0.17% fraud)
Uses Logistic Regression and Random Forest
Evaluates using precision, recall, F1-score, ROC-AUC
Implements threshold tuning for real-world decision making
Key Insight

Accuracy is misleading for imbalanced data; recall and precision are more meaningful.
